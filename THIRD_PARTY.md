# Third-party assets

## Staunton chess piece meshes

- Project: Staunton-Pieces
- Author/source: clarkerubber
- Source: https://github.com/clarkerubber/Staunton-Pieces
- License: MIT
- Local license copy: `assets/models/staunton/LICENSE.txt`

The six Staunton STL sources were converted to Godot-compatible OBJ meshes, reoriented, normalized to game scale, and vertex-cluster optimized for Android. Runtime materials are original project materials and are not copied from the user's visual reference sheets.
