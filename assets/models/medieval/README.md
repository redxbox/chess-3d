# Medieval chess set

Hand-sculpted set of six pieces, supplied by the project author as six GLB
files (`pawn.glb` … `king.glb`, each ~200–320k vertices and ~10 MB).

## What is here

`pawn.obj` … `king.obj`, generated by `tools/prepare_medieval_set.py`:

- **Decimated** from roughly 500k triangles per piece to 10 000, with
  `fast-simplification`. The carved surface, the hewn base and the folds of the
  king's robe survive; the 56 MB of source geometry does not.
- **Scaled onto this project's height ladder** — the uploads were all exactly
  1.0 unit tall, so without this a pawn would stand as tall as a king. Heights
  now match the Staunton set: pawn 0.91, rook 1.18, knight 1.33, bishop 1.34,
  queen 1.49, king 1.62.
- **Standing on y = 0**, centred in X/Z, +Y up, exactly as `main.gd` places
  every body.
- Positions and faces only, like the Staunton OBJs. `_piece_mesh()` welds the
  export's duplicated vertices, generates smooth corner normals and projects a
  cylindrical UV set at load time.

Total: 1.8 MB for the six bodies.

## Regenerating

```sh
python3 tools/prepare_medieval_set.py /path/to/glb/folder assets/models/medieval
```

Requires `numpy trimesh fast-simplification` (build-time only; the OBJs are
committed).

## Facing

The sculpts face **+Z**: the knight is a profile looking that way, and the king
and queen hold their staff and orb in front of them, i.e. toward +Z. The
Staunton bodies face −Z. `_facing_yaw()` in `src/main/main.gd` is the single
place that knows this, and it turns each army's asymmetric pieces toward the
enemy (White up the board, Black down it).
