# Chess 3D

A 3D chess game inspired by Windows 7's Chess Titans, built with Godot 4.

## Features (planned)
- 3D board with glossy, glass-like pieces
- Full chess rules (check, checkmate, castling, en passant, promotion)
- Camera rotation & zoom
- Android APK export

## Development
Requires Godot 4.x. Open `project.godot` in the editor.

## Building for Android
Use the prepared `export_presets.cfg`, then Project → Export → Android.
